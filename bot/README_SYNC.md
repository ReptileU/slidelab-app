# Как работает синхронизация с GitHub

Главная версия кода — здесь, в папке `bot/` этого репозитория.

Бот на компьютере раз в 3 минуты сверяется с GitHub и сам подтягивает изменения:
- `bot.py`, `publisher.py` — после проверки на ошибки бот перезапускается с новой версией
  (если в новой версии ошибка — остаётся на старой и пишет владельцу);
- `posts/*.txt` — посты канала (новый или изменённый пост придёт на одобрение).

Подтянуть сразу, не дожидаясь: команда `/sync` в боте (только для владельца).

Не синхронизируются и в репозиторий не загружаются: `settings.txt` (токен, карты), заказы, медиа, `posts/state.json`.
Выключить синхронизацию: строка `GH_SYNC_MIN=0` в `settings.txt`.
