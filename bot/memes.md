# База актуальных мемов для презентаций SlideLab

Обновлено: **27.10.2026** · обновляется раз в неделю автоматически (задача «SlideLab — обновить базу мемов»).

Для чего: опция «😄 С юмором» в заказе. Если клиент её включил, в презентацию добавляются 1–2 уместных мема по теме.

## Стиль SlideLab-юмора (эталон — презентация Тимура «ADS — реклама»)

Юмор не «вставлен сбоку», а встроен в ритм рассказа. Приёмы:

1. **Вопрос → мем-ответ.** Чёрный слайд с риторическим вопросом крупно («Даст ли это результат?»), следующий слайд — мем-реакция («НЕТОЧНО» со злой птичкой). Самый сильный приём.
2. **Главы-«титры».** Чёрный фон, крупная белая цифра + красное слово («1 · СПАМ», «2 · КОНФЛИКТ», «3 · КРИНЖ-реклама»). Создают драматическую паузу перед шуткой.
3. **Обложка с иронией.** Рядом с серьёзным заголовком — узнаваемый мем по теме (реклама → спам-баннер «Наталья, 300 метров от вас»).
4. **Мем как иллюстрация к сухому списку.** Список «6 причин…» + мем-реакция сбоку (пенсионеры: «некрасиво» / «мне тоже не нравится»).
5. **Реальные смешные кейсы по теме** — главная «скрытая шутка». Не выдуманный мем, а настоящий пример, который сам по себе смешной: кринжовая реклама, бренд с двусмысленным названием, абсурдный факт. Грубое название — показывается как есть только если это реальное название бренда/кейса и оно не написано матом прямо; иначе — со звёздочками.
6. **Финал-мем «Спасибо за внимание»** в формате пацанских цитат / узнаваемого шаблона.

**Частота:** примерно 1 юмористический «бит» на 3–4 слайда (5–7 на 20 слайдов). Содержание всё равно главное — каждый мем подводит к мысли слайда, а не отвлекает.

## Правила использования (обязательно)

1. **Дозировка:** по стилю выше — 1 шутка на 3–4 слайда. Для защиты диплома/конференции (если клиент так указал) — не больше 2–3 мягких.
2. **Мем должен быть связан с темой.** Подпись переписывается под тему презентации — не вставлять мем ради мема.
3. **Цензура, но понятно.** Грубые версии — только со звёздочками или смягчённым словом, которое все узнают: «Вот такая \*\*\*, собачка», «египетская сила». Мат буквами — никогда.
4. **Только понятные широкой аудитории мемы** — статус 🔥 или ✅. Мемы со статусом ⏳ (угасают) — только если очень в тему. Узкие «для своих» (brainrot без контекста) — не брать.
5. **Без картинок чужих людей и кадров из фильмов.** Мем воссоздаётся форматом: своя иллюстрация (Higgsfield) в стиле мема + узнаваемая подпись. Никаких фото реальных знаменитостей, политиков, чиновников.
6. **Табу:** политика, война, религия, национальности, внешность, скандалы с реальными людьми (стрельба, измены, коррупция), смерть, болезни, 18+. Если тема презентации серьёзная (трагедии, болезни, война, катастрофы) — **мемы не добавляются вовсе**, даже если опция включена; об этом пишется Тимуру в отчёте.
7. Для преподавательской аудитории (защита, конференция) — самые мягкие: «Котёнок с мечом», «Grr Mondays», «Белка в торнадо».

Статусы: 🔥 на пике · ✅ держится, все знают · ⏳ угасает · ❌ не использовать

## Мемы-реакции на все случаи (вечные, все узнают)

Подходят под приём «вопрос → мем-ответ» и под финал. Берутся чаще всего.

| Мем | Статус | Когда ставить |
|---|---|---|
| **«НЕТОЧНО»** (злая розовая птичка) | ✅ | Ответ на «Даст ли это результат?», «Это сработает?» |
| **«Наталья, 300 метров от вас»** (спам-баннер) | ✅ | Реклама, спам, навязчивый маркетинг, интернет-мошенничество |
| **Пенсионеры у моря: «некрасиво» / «мне тоже не нравится»** | ✅ | Критика, недостатки, «почему людям не нравится…» |
| **«Спасибо за внимание» в стиле пацанских цитат** (мужчина в костюме, подпись крупно белым) | ✅ | Финальный слайд |
| **«Аналог»** (одно слово на чёрном перед сравнением) | ✅ | Перед слайдом «оригинал vs копия» |
| **«Ожидание / реальность»** | ✅ | Планы vs итоги, реклама vs продукт |
| **«Это норма?»** / **«А что, так можно было?»** | ✅ | Удивительный факт, лайфхак, неожиданное решение |
| **«Я сделяль»** | ⏳ | Итог работы, «готовый продукт» |
